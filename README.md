# Dự án Kỹ năng số - Quản lý phiên bản
## Mục tiêu dự án
Thực hành quản lý phiên bản, làm việc với nhánh (branch) và đồng bộ mã nguồn lên GitHub thông qua GitHub Desktop.
## Nguồn dữ liệu
Dữ liệu mẫu tự tạo (giả lập/không định danh) phục vụ mục đích học tập.
Commit giống như việc nhấn "Lưu phiên bản" để đóng gói các thay đổi tại máy cá nhân kèm theo ghi chú về những gì vừa sửa. Branch tạo ra một bản sao làm việc song song, cho phép bạn tự do chỉnh sửa báo cáo hay viết thêm code mà không sợ làm hỏng phiên bản chính. Khi muốn đưa toàn bộ lịch sử thay đổi từ máy tính lên GitHub để lưu trữ hoặc chia sẻ, ta dùng lệnh push. Còn khi cần lấy dữ liệu hoặc các cập nhật mới từ trên GitHub về lại máy tính của mình, ta sử dụng lệnh pull.
